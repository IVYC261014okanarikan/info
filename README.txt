トリッカル紹介サイト

【ファイル】
- index.html : ページ構造
- style.css  : デザイン
- script.js  : メニュー、キャラクター選択、スクロール演出
- img/       : 画像を入れるフォルダ

【画像について】
img フォルダに次の名前で画像を入れてください。
main.jpg   : トップのメイン画像
world.jpg  : ゲームの世界観
elfin.jpg  : エルフィン
komi.jpg   : コミー
aya.jpg    : アヤ

画像がまだない場合でも、ページの構造とデザインは確認できますが、画像部分は表示されません。
ご自身で用意した画像を使う場合は、各画像の利用条件を確認してください。

【表示方法】
1. ZIPを展開します。
2. Visual Studio Codeで triccal-site フォルダを開きます。
3. index.html を右クリックし、Live Serverで開きます（Live Server拡張機能が必要です）。
